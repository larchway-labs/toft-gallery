Send it on a schedule

Toft calls a path this app publishes, on whatever schedule an administrator sets. Create the task on the app's Automation tab with:

Path
/tasks/report
Method
POST
Parameters
{"report": "low_stock", "channel": "slack", "to": "ops@example.com"}

report is one of inventory, low_stock or movements; channel is slack, email or both. Two schedules on the same path with different parameters is the point — one report, weekly and monthly, without a second endpoint.

The run's log and its result appear on the Automation tab, and the delivery appears in the table beside this. The work happens inside the request: if the task times out, the run is a failure, so keep the window wide enough for the register you have.
